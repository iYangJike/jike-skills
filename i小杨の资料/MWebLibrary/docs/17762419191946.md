# dify 智能客服

1. 创建 火山引擎 API 秘钥
2. 在 dify 平台创建相关智能客服模版
3. 将dify 生成的 iframe 对话框，集成到项目中

**火山引擎 API key**

1. 进入控制台 选择 ‘火山方舟’
2. 侧边栏中，选中 AIP Key 管理
3. 创建一个 API 秘钥
4. 点击 在线推理，并创建推理接入点
5. 可以选择 deep-seek 模型

**dify 相关**
- [dify 官网地址](https://cloud.dify.ai/apps)
1. 登录 Dify 网站
2. 创建空白应用
3. 选择 聊天助手
4. 创建之后，点击头像，选择设置。
5. 点击模型供应商，选择 火山引擎
6. 在 火山引擎的选项卡中，点击 添加模型，
7. 填入 api-key 和 end-point-id
8. 点击创建的 聊天机器人，选择刚添加的 火山引擎接入点。
9. 测试可以正常回复之后，点击发布，选择嵌入网页
10. 复制 生成的 iframe，让ai帮忙生成相关功能

**聊天机器人 相关**
提示词
```
你是一个智能客服，会检索你知识库中的内容回答用户，如果没有找到相关问题，请告诉用户，联系@元子
```

**end-point-id 位置**

> 点击在 火山引擎创建好的推理模型（deep-seek-v3.2)，最上面名称下边，有一个 ep-xx  开头的id，复制填入即可。
